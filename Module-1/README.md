# Module 1: Introduction to AI & Python

## Module Name

Introduction to AI & Python

## Description

This module introduces the fundamentals of Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning. It also covers Python programming basics and beginner-friendly Python practice programs.

## Learning Objectives

- Understand the basics of Artificial Intelligence and Machine Learning.
- Learn the differences between AI, ML, and Deep Learning.
- Explore real-world applications of AI.
- Learn Python variables and data types.
- Understand Python operators and their symbols.
- Practice conditional statements, loops, and lists.
- Learn functions and write beginner-friendly Python programs.

## Topics Covered

### Day 1: Introduction to AI & ML
- What is Artificial Intelligence?
- What is Machine Learning?
- What is Deep Learning?
- Differences between AI, ML, and Deep Learning.
- Real-world applications of AI.

### Day 2: Python Basics
- Variables and data types.
- Arithmetic, comparison, assignment, and logical operators.
- Python input and output.

### Day 3: Conditions, Loops, and Lists
- if, elif, and else statements.
- for and while loops.
- Lists and list operations.

### Day 4: Functions and Beginner Programs
- Defining and calling functions.
- Writing beginner-friendly Python programs.
- Practicing Python programming concepts.
