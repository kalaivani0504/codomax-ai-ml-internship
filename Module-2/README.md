# Module 2: Python Mini Project

## Project Name
Student Grade Calculator

## Description
This Python project accepts a student's marks in five subjects and calculates the total marks, percentage, grade, and pass/fail result.

## Concepts Used
- Variables and data types
- User input
- Type conversion
- Functions
- Loops
- Conditional statements
- Arithmetic operations
- Input validation

## Language
Python

## How to Run
1. Install Python.
2. Open a terminal in the project folder.
3. Run: `python student_grade_calculator.py`
